# Exercices sur les chemins HTML

Cet exercice consiste à repérer les erreurs de liens dans une arborescence d'un site web pour apprendre le fonctionnement et la syntaxe des balises `<a>`. 

| Fichier                         | Ligne fautive                                                | Ligne corrigée                                               | Explication                                                  |
| ------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| site/index.html                 | `<link rel="stylesheet" href="../css/style.css">`            | `<link rel="stylesheet" href="css/style.css">`               | Le lien href vers la feuille de style "../css/style.css" remonte d'un niveau d'arborescence avec le "../" alors que le dossier "css/" se trouve bien au même niveau que la page index.html. |
| site/index.html                 | `<img src="img/Logo.png" alt="Logo du club">`                | `<img src="img/logo.png" alt="Logo du club">`                | Le lien src "img/Logo.png" est mal écrit : le fichier logo.png n'a pas de majuscule et les liens sont sensibles à la casse. |
| site/index.html                 | `<a href="pages\contact.html">Contact</a>`                   | `<a href="pages/contact.html">Contact</a>`                   | Le lien href "pages\contact.html" est mal écrit : on n'utilise pas de anti-slash dans un chemin d'accès en HTML. |
| site/index.html                 | `<a href="doc/plaquette.pdf">Plaquette</a>`                  | `<a href="docs/plaquette.pdf">Plaquette</a>`                 | Le lien href "doc/plaquette.pdf" a une erreur, le dossier s'appelle "docs". |
| site/pages/contact.html         | `<a href="index.html">Accueil</a>`                           | `<a href="../index.html">Accueil</a>`                        | Le lien href "index.html" n'indique pas le "../" pour remonter dans le répertoire parent, vu que la page "contact.html" se trouve dans le dossier "pages/" |
| site/pages/contact.html         | `<img src="../img/photos/equipe.jpeg" alt="L'équipe du club">` | `<img src="../img/photos/equipe.jpg" alt="L'équipe du club">` | Le lien src "../img/photos/equipe.jpeg" est mal écrit car le fichier s'appelle "equipe.jpg." |
| site/pages/services/reseau.html | `<a href="contact.html">Nous contacter</a>`                  | `<a href="../contact.html">Nous contacter</a>`               | Le lien href "contact.html" n'indique pas le "../" pour remonter dans le répertoire parent, vu que la page "reseau.html" se trouve dans le dossier "services/". |
| site/pages/services/reseau.html | `<img src="../img/icones/mail.svg" alt="">`                  | `<img src="../../img/icones/mail.svg" alt="">`               | Le lien src "../img/icones/mail.svg" remonte dans le répertoire parent "pages/", seulement le répertoire "img/" est dans la racine "site/". Il faut encore monter d'un niveau en rajoutant un "../". |
