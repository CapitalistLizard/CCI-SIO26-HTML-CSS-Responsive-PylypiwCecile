# Exercices HTML - Première page

```html
<!DOCTYPE html>
<html lang="fr">
    <head>
        <meta charset="UTF-8">
        <title>Ma pemière page - BTS SIO SISR</title>
    </head>
    <body>
        <h1>Bienvenue</h1>
        <p>
            Salut, je suis Cécile, je suis en BTS SIO SISR, j'aime les lézards et les gadgets rigolos. </br>
            Les gens qui utilisent Windows sont les mêmes que ceux qui mettent du ketchup dans leurs pâtes.
        </p>
    </body>
</html>
```

## Explications

- Le document est déclaré en HTML5 avec la mention <!DOCTYPE>. 
- La langue du document est déclarée avec l'attribut "lang" dans la balise <html>
- L'encodage est déclaré avec la balise <meta> et l'attribut "charset", le UTF-8 est un type d'encodage des caractères relativement universel en HTML qui permet d'afficher les accents, entre autres.
- Le titre de l'onglet est déclaré avec la balise <title> dans le <head> indiquant les attributs de la page HTML.
- Le tire principal visible est indiqué avec la balise h1
- Les paragraphes sont indiqués par la balise <p>. J'ai rajouté le br pour sauter une ligne.
